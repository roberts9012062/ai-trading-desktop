# 冠军因子收藏与挂载误拦修复

用户反馈：封存通过的冠军因子仍提示“该因子依赖尚未接入实盘的直连数据，暂仅支持本地研究，不支持实盘收藏或挂载”。

## 定位结果

该提示来自客户端。因子实验室、超级挖掘页面和收藏 API 客户端都存在提前拦截，收藏请求因此尚未到达服务器。服务器现有收藏 API 能保存公式、封存结果和来源元数据；本次用隔离的内存数据库验证了真实 API 的保存与读取。

旧规则把研究数据来源 gate_usdt、旧 local_only 标记当成永久执行权限；还按桌面特征编号判断已经转换为服务器 v3 的公式，误将 v3 的 STREAK/VWAP_DEV 判作强平输入，并漏识别真正的 v3 缺失输入。

修复后，收藏保存配方和验证证据；挂载按整条公式的编码与实际数据依赖判断。保留原有样本外亏损、旧内核和样本外复测检查，不修改挖掘评分与交易规则。AI 任务不再通过额外读取旧收藏标记判定执行能力。

服务器 evaluate_task 原先仅为因子任务和决策因子混合任务补充衍生数据，漏掉挂载参考因子的 AI 任务。本次补充这一入口；不挂因子的 AI 任务和其他普通策略保持原路径。

## 能力边界

QUOTE_ILLIQ20、LIQUIDATION_IMBALANCE、AVG_TRADE_QUOTE 仍缺少服务器直连输入。其配方可收藏；服务器 AI 参考因子挂载继续拦截，不将缺失数据伪造为零。现有切换本地执行入口的服务器支持并未在本次补齐，不能把该入口视为已完成的本地实盘引擎。

公式可执行不等于实时数据必定可得，也不等于能获利。本次未验证具体用户记录的来源标记或当前账户的真实行情质量。

源码修复需更新桌面端，并部署或重启相应服务器版本后才会作用于正在运行的软件。
