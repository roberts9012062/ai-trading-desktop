### 2. ✅ 全新简化页面（v2 版本）

**文件**：`src/components/shortline-lab/shortline-lab-page-v2.tsx`

#### 核心改进

**流程简化**：
- ❌ 旧版：手动回填 → 手动配置 → 手动启动 → 手动查看（4 步）
- ✅ 新版：**一键启动**（自动回填 → 挖掘 → 展示）

**参数精简**：
- ❌ 旧版：9 个参数（币种/周期/种群/代数/深度/折数/渠道/引擎/回填区间）
- ✅ 新版：**3 个核心参数**（币种/周期/算力）
- 自动设置：种群 300、代数 30、深度 5、折数 3、渠道 binance_usdt

**界面现代化**：
```
旧版布局：
┌─────────────────────┐

┌─────────────────────┐
│ 标题 + 说明          │
├─────────────────────┤
```

- 进度条：渐变填充 + 平滑过渡
- 文字层级：标题 sm/白色，说明 xs/灰色
