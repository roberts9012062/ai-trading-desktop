# v0.2.20 因子权限与旧任务管理修复

- 因子实验室允许普通本地专属公式收藏用于本地回放，保留样本外及内核版本检查。
- 两处收藏入口与收藏 API 统一拦截研究专用因子；兼容仅有 Gate 渠道标记或新特征 token、缺少 research_only 标记的记录。
- AI 任务的收藏选择器标示不可用公式；新建及编辑 AI 任务在提交前重新校验收藏元数据，阻止旧收藏绕过限制。本地挖掘不等于 AI 任务的服务端信号具备相同输入。
- 恢复旧服务端挖掘任务的列表、详情、暂停、取消和删除；新任务仅本地创建，旧服务端任务不开放恢复。找不到任务所属引擎时明确报错，不再错误路由至本地。

验证：类型检查通过；Vitest 151 通过、1 跳过（Node 无 WebGPU）；生产构建通过，保留既有大包与混合导入提示。新增 9 项回归测试覆盖收藏和 AI 任务提交边界。Chrome 页面测试使用模拟服务端任务，确认旧任务显示、暂停 API 路由及无服务端恢复/新建入口，未操作真实交易或真实远端任务。

本次未改变因子内核与资金费率收益成本口径。
