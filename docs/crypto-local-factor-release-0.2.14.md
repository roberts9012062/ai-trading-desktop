# v0.2.14 本地加密因子优化

范围：超级因子挖掘、因子实验室的本地 CPU / WebGPU。服务端计算未改动。

## 已实现

- 两处新建本地 USDT 币种搜索自动使用 `crypto_ohlcv_v1`；配置随超级挖掘任务持久化，跨内核版本恢复有检查。
- 新配置按 365 天、24 小时年化；历史未启用配置的任务保留原年度口径。
- 追加 12 个特征（ID 40–51）：UTC 日内/七日周期与周末、6/24 根波动调整动量、收益波动、非流动性代理、方向成交量代理、下行风险占比、通道位置。
- 新增 4 个算子（token 104–107）：20/60 根中心秩、10/20 根线性衰减。原特征与算子 ID 未移动。
- 中心秩将相近值按 `1e-6 × max(1, abs(current))` 判作并列；周期特征统一保留 7 位小数，避免 f32/f64 把理论相等值排序成不同结果。
- 训练段可用性过滤移除常数/无效特征及旧期货时间特征。新增量价风险特征获得适度抽样权重；初始化、变异和停滞重启共用抽样器。
- CPU 候选训练指标增加有界缓存；矩阵缓存改为所有输入字段内容哈希，避免中间 K 线量价修正后复用旧结果。
- 新配置的默认搜索成本仅由训练段价格估计，不读取封存段价格。仍采用静态手续费加 tick 滑点模型。
- 新配置/新 token 的分段评估使用完整历史前缀，覆盖嵌套窗口和 EMA 状态；新 token 的最终归一化不再依赖全段标准差分支。
- CPU/GPU 的逐代冠军报告不揭示封存指标，只在最终代计算；既有验证筛选不因此放松。
- 新算子加入 Python、TS 参考实现、WGSL、中文公式、LLM 词表及本地专属判断。WGSL 算子边界由注册表数量生成。
- 实验室本地搜索及后续单因子回测正确透传数据渠道；回测沿用冠军的市场配置和成本，组合评估也传递配置。

真实 Chrome WebGPU 对 CPython NumPy f64：固定合成小时行情，52 个矩阵行、40 个训练可用特征，504 个候选中455个 CPU 合法非常数候选。

## 边界

- 本次没有接入历史 funding/OI/盘口/清算数据，没有证明真实行情上的超额收益提升，也未声称端到端提速比例。
- 当前仍是价量多空信号研究：现货 K 线代理不等同于可执行现货做空或含资金费率的永续回测。两个入口均展示此说明。
- 新特征采用固定因果窗口；旧特征的历史归一化定义保留，尚未完成其全链路版本化迁移。完整历史前缀增加了评估上下文长度，长历史任务仍需实测时间和内存。
- GPU 仍为 f32 粗排，少数复杂表达式存在数值敏感性；冠军最终数字始终由 f64 精算输出。CPU 支持 EMA，GPU 随机搜索仍不生成 EMA，两个引擎搜索轨迹不宣称相同。
- 真 GPU 对拍使用合成数据及 Chrome，不等同于安装包 WebView2、真实多币种长跑验收。
