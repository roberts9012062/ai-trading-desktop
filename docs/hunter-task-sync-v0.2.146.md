# 多周期猎手任务与收益对比同步（v0.2.146）

收益对比的浮盈榜与猎手明细使用同一份未结束子任务集合。待成交任务也显示，已持仓任务不再因尚无曲线采样而隐藏。曲线只使用真实有效采样；完整平仓结束的单移出活动明细。

服务器返回 `position_sync_status` 区分持仓待对账与读取中断。猎手仍有未结束已成交单、但严格归属查询未取得持仓时，显示“持仓待对账”，浮盈显示 `--`。读取异常不会被解释为确认空仓，不会清除已有轨迹或采样虚假的零收益。持仓恢复后继续记录；明确空仓后清除。

实际 XRP 复现：交易所持仓 700 XRP，任务成交账本 698 XRP。保留严格数量归属校验，不把数量不一致的外部仓位浮盈记入该任务；界面保留该单并标明待对账。此修改不提交或补写交易订单。

猎手收到服务器新挂载的任务 ID 后，立即补拉缺失任务列表，减少两个面板轮询之间的显示差异。
