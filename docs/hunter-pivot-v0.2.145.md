# 枢轴确认计时与收盘反转入场（v0.2.145）

新版本的入场新鲜度从参数 P（盘中预确认最少右侧根数）对应的确认信号出现时开始计龄。信号出现后的第 0、1、2 根可进行入场复核。L6/R6/P2 的波谷在三根前时，信号年龄为一根，可进入复核；P6 的正式信号在六根右侧K线收盘时才开始计龄。多周期猎手的有效期也按同一口径计算，同一枢轴身份保持不变，避免重复开仓。

多周期猎手新增收盘反转入场条件：枢轴右侧最后一根已收盘K线必须是阳线且收盘高于前一根，才可做多；做空要求阴线且收盘低于前一根。最新行情和执行报价须维持确认收盘价的有利一侧。只有盘中K线变红或变绿不足以入场。扫描、挂载、执行前和未成交挂单均复核，确认失效则取消未成交入场。已有持仓仍由原锁利、兜底和冻结枢轴退出规则管理。

MINAUSDT 在 2026-10-08 16:00 北京时间的实际入场K线已保存为回归夹具。它的枢轴右侧已收盘K线仍为阴线，新规则会拒绝该入场；这验证了该形态被拦截，未进行盈利验证。

新建猎手的默认识别门槛由最小振幅 1.5% / ATR 1.5 倍调整为 1% / ATR 1 倍，左右与预确认参数继续可调。已有任务的自定义参数及已有单的冻结参数保留。普通用户和 VIP 用户使用本机扫描；服务器托管暂时仅管理员可见、可用（v0.2.144 已部署）。
