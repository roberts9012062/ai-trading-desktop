# 个人实盘账户来源（v0.2.213）

业务服务器 b.00n.top 已由用户停用。本次故障来自客户端仍把未绑定账户、
凭证保存及账户授权状态发送到旧业务服务器，并非中心未能返回 OKX 余额。

## 两种模式

交易所接入与数据配置页提供“个人实盘账户来源”选择，默认单机模式。
切换后重新加载当前窗口，关闭旧会话连接并重置内存缓存；保留本机账户。

| 功能 | 单机模式 | 服务器模式 |
| --- | --- | --- |
| 凭证读取、保存与删除 | 本机 SQL + Windows DPAPI，按桌面账号隔离 | 业务服务器账户接口 |
| 余额、持仓、委托、成交、账单、费用与收益 | 本机签名，经 API VALUE COLLECTION；未配置中心 Key 时按原规则直连 OKX | 业务服务器账户接口 |
| 私有账户推送 | 本机登录签名，经中心私有 WS；无需旧业务签名 WS | 业务服务器推送 |
| 缺少本机凭证 | 明确提示在交易所接入页配置，不回退旧服务器 | 由业务服务器返回配置状态 |
| 服务器交易授权 | 缓存状态；没有授权时允许配置和只读，不授予交易能力 | 向业务服务器读取 |
| 下单、撤单、平仓及任务 | 保留服务器绑定、授权与执行权限制；未绑定账户明确拒绝 | 保留原服务端授权规则 |

接口中心 Key 不是个人 OKX 凭证。用户在数据配置保存中心 Key，并在交易所
接入页填写自己的 OKX API Key、Secret、Passphrase；实盘 API 取消“模拟盘”
选框，模拟 API 保持勾选。旧服务器独有的凭证无法在停服后自动恢复。

本地保存真实账户凭证只开放读取，不会生成 server_bound、修改真实交易授权
或开通托管。原生金融入口仍校验绑定和独立授权；未支持的金融操作不会通过
单机读取路径转发。创建及重启任务仍需显式服务器登录。猎手仍隐藏且不实现。

## 修复点

- `tryPreparedLocalLiveRequest` 将本机配置和普通只读调用与金融命令分开；
  非服务器绑定凭证也能读取，普通读取无需执行权租约。
- 本机凭证保存成功后保留新凭证并通知账户变化，避免旧的“保存后清除服务器
  缓存副本”逻辑误删刚保存的本机账户。
- 收益查询直接使用本机密封凭证，移除中心收益命令中的旧业务服务器凭证租约。
- 服务器模式绕过本机账户 RPC；私有连接、收益计算和账户来源说明跟随模式。
- 服务器账户更新不会清除用户独立配置、尚未绑定服务器的本机凭证。

## 验证边界

前端回归与完整页面/IPC 契约验收使用合成账户与模拟原生桥，覆盖真实账户配置
分支、保存后保留、无业务连接读取、金融操作拒绝及两种模式切换。
真实网络验收另用已授权 OKX 模拟测试凭证，通过原生生产 HTTP 池经中心签票
读取余额、持仓和挂单，不执行金融写入。未获得用户自己的实盘 API 凭证，
不把模拟盘联调称作用户实盘验收。安装包与更新签名另由发布流水线核验。
