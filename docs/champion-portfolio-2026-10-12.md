# Champion 组合超级因子（v0.2.182）

需求：组合超级因子进入 Champion 排行，可收藏、查看数据，不再放在页面底部。

## 实现

- 因子实验室与超级因子任务共用排行：组合固定在单因子之前；无单因子冠军时仍显示组合。
- 独立组合身份，不把成员冒充组合，也不把组合综合分、OOS、DSR 补为虚构数值。
- 排行采用实际通过的等权或 IC 加权口径，并注明评估区间。点击组合行或“查看数据”展开原始评估：年化、Sortino、Calmar、双成本压力、两种口径的逐折结果、相关性和成员配方。
- 合格组合可收藏；失败或成员信息不足的组合保留数据入口，不标为合格超级因子。
- 收藏沿用已部署服务端的嵌套 tokens API，无数据库迁移。`metrics.portfolio_snapshot` 保存本次组合评估；单因子与组合采用独立去重键空间。
- “我的收藏”与因子收藏夹均可重新打开组合数据；旧组合收藏无评估快照时明确说明，只显示已有成员。
- 组合收藏不进入只接受单公式的任务下拉，不做扁平化，不将 IC 加权组合按等权执行。此更新提供评估快照查看，不新增组合权益曲线或重新回测功能。
- 本次只修改桌面仓库，服务端已有组合收藏能力，无服务端代码或 Docker 变更。

## 验证

- `pnpm typecheck` 通过；`pnpm build` 通过，已有分包大小提示不影响构建。
- 发布相关 11 个 Vitest 套件共 77 项通过，新增组合排行与收藏往返测试进入 release 工作流。
- Edge 无头浏览器隔离验证通过：首行位置、仅 IC 通过的显示、无单因子场景、展开数据、收藏失败重试、刷新去重、两个收藏入口、失败状态、窄窗口。
- 浏览器 API 使用隔离模拟响应，未向用户真实收藏写入验收数据。服务端兼容性依据现有 `FavoriteCreateRequest`、`add_favorite` 的嵌套 tokens 与任意 metrics JSON 契约。
- 本地验收截图和结果在 `.local-data/portfolio-*`，不进入发布包。
