# 工作台和 AI 交易展示查询接入 Snippet

用户授权继续替换可迁移数据读取。选择复用认证 RPC 与交易所适配器，不在桌面复制账单/手续费/任务归属计算。替代方案是把原始私有字段与归属映射下发桌面聚合，易造成版本口径漂移；仅继续改公共行情则无法迁移收益分析。

- 新增只读 RPC 白名单：账户日收益、今日任务成交明细、AI 任务列表/详情/成交/交易标记、收益对比总收益、任务资金源。账单/资金费/成交/持仓/余额经现有 Snippet；分页与符号数量换算仍在 OKX 适配器。
- 图表持仓波段采样与排行榜继续使用现有规范数据。任务归属、累计任务盈亏、胜率、猎手费用账本、历史权益曲线是服务器数据库能力，保留现有算法。交易所 I/O 迁移不等于把任务逻辑迁移到 Snippet。
- 每个只读操作内复用成功 GET（含合约规格），不重复为每张任务卡拉同一持仓。收益统计缓存隔离到当前认证 WS 连接，60 秒 TTL，区分 API 账户与 demo；不污染服务器任务共享缓存。
- 展示用成交查询可代理；订单镜像回填、开仓成交归属修复仍只接受服务器直接回读。新增只读白名单禁止任务创建/启停/下单/删除通过此通道。
- 全局服务器模式启用后原 HTTP 通道生效；429/超时仍回退，写请求不重放。现有 REST 2.1 Snippet 已支持所需查询，本次不要求重新部署 Cloudflare。
- 验证：只读白名单与写拒绝、每操作去重、缓存隔离、费用/资金费口径、任务归属、直接回读；桌面类型/测试/构建；线上只读及模拟账户对比、强制 429、路由开关。两仓提交推送，Docker 更新，桌面 v0.2.157 签名发布。
