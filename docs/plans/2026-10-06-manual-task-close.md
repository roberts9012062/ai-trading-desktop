# 任务卡一键平仓

用户要求：每个任务卡增加一键平仓，满意当前利润时主动结束本笔持仓，并触发锁利冷却。沿用现有任务启停状态和策略参数。

入口覆盖任务列表卡、收益对比的单个任务卡、任务详情及猎手子任务列表。猎手组的汇总收益卡不执行组内全部平仓。

按钮直接请求任务级市价平仓，空仓、提交中和成交待确认时禁用；服务器仅使用当前用户、当前交易盘、当前任务的实际成交归属。完整成交后进入锁利冷却，使用现有冷却配置，至少跳过一次有效开仓信号。同一信号的重复轮询不重复扣减。此操作独立于自动锁利开关，不自动启用未来持仓的利润追踪。

实盘减仓经 live_trading 和交易所适配器执行。下单前持久化镜像客户端订单号与锁利平仓意图，超时后按原意图对账。持仓缺失、部分成交或接单回执不能启动冷却。开仓余单须先撤销确认；混合仓位、方向和数量不一致时拒绝接管。

普通 AI、决策模型、量化及因子任务保留运行状态；预测任务确认后进入下一轮并受冷却门控；短线任务重置预期仓位并清理自己的保护单；猎手单笔机会完成后将冷却传递至猎手组。暂停/结束任务的在途平仓仍由后台确认。

验收使用隔离数据库和模拟交易所，覆盖完整/部分成交、重复请求、冷却去重、下单失败、跨账户/交易盘、混合仓拒绝和各任务类型。界面验收页面屏蔽全部真实 API，不操作生产持仓。
