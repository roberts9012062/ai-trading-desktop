# v0.2.172 桌面任务导出保存修复

服务器真实账号只读导出验证返回 HTTP 200、完整配置 36 字段及附件文件名。旧客户端在拿到文件后创建 Blob 链接、点击并立即撤销 URL；没有桌面原生保存流程或成功提示，无法确认落盘。

桌面导出改为 Rust 端原生另存为窗口，绑定客户端父窗口，只将响应原始字节写到用户选择的位置。完成落盘后显示路径，取消不误报成功，写入错误展示原因。任务配置、三类收藏、单项/分类/全部收藏及现有日志导出共用保存工具。

下载请求统一解析当前产品服务器地址，防止相对日志地址错连 WebView 本地源；不向其他源发送登录令牌。限制 32 MB，只支持 JSON/CSV，文件名不能带路径；未开放通用任意路径写入权限。浏览器调试下载延迟回收 Blob URL，保留原始字节与中文文件名。

验证：新增 6 项 TypeScript 下载回归（先失败再修复）、原生 4 项取消/文件名/字节落盘/错误测试；1029 项桌面测试通过、2 项按配置跳过；TypeScript 与 Vite 构建通过。发布工作流加入原生导出测试。

本次只有客户端变更，服务器导出接口正常，无需重启托管任务后端。
