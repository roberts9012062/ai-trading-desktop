# 原创建流程与可选单机 Key

继续使用 AI 交易的原创建 AI、量化和收藏任务弹窗，提交由独立适配层连接现有已认证 Go 托管协议。删除托管页的第二套任务创建表单。服务器分配任务 ID，结果未知只查询原请求，不离线落任务、不自动重试。原表单的策略、仓位、风控参数逐项传递；未实现的语义明确拒绝，不能悄悄丢弃。

原创建弹窗中显示明确选择的服务器交易账户，模型列表使用服务器已加密保存的模型记录。任务卡片读取服务器事实。原表单的自动开始只有在创建和注册已确认后才发送一次中心 CAS 恢复请求；结果未知保留创建事实并提示核对，不重新创建。

单机入口的 Key 可留空。读取当前选中本地配置已保存的 Key，禁止扫描其他账号。没有 Key 或中心暂不可用也能进入本地工作区；本地会话不代表中心身份或执行权限。中心任务读取与控制仍需独立验证，单机始终不能创建任务。

使用隔离夹具验证原按钮/弹窗、参数保留、服务器拒绝/未知结果、身份变化和空 Key 登录。完成客户端构建、签名安装及更新清单发布，保留原数据。
