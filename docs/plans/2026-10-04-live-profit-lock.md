# 运行任务锁利开关

在通用 TaskActions 中新增独立锁利入口，任务卡片和详情共用，运行且有持仓、无法完整修改任务配置时也可使用。多周期猎手面板提供相同入口。原有操作按钮和完整改比例表单保持不变。

点击未开启任务的“开启锁利”后打开窗口，开关选中、下拉默认内置自动挡；已有开启配置独立回填。下拉显示内置模板和当前账号服务器上的个人模板，选择模板仅复制参数。保存并生效提交，取消不改任务，关闭开关后保存发送明确 disabled 配置。

服务器新增只允许 profit_lock 字段的窄更新接口，复用严格阈值校验，按用户及 JWT 交易模式隔离。持仓中不查行情、不下单，仅行锁保存配置，其他 close_rules、stop_rules、杠杆、兜底阈值、任务状态和 profit_lock_state 均保留。已有锁利线不降、待确认平仓不能丢失。

猎手更新只同步当前未结束子任务及父配置；历史子任务保留副本。锁顺序与挂载、运行器一致（User -> Task -> Hunter），避免父子逆序造成死锁；挂载在 User 锁下串行，后续子任务继承最新配置。

界面轮询不覆盖未保存草稿；账户或目标任务改变时关闭窗口。保存失败留在窗口显示错误，可重试。服务端下一轮执行原有锁利算法与成交确认/冷却逻辑。

验证：持仓热改、原规则与状态保留、无新增订单、关开默认和回填、账号/交易模式隔离、非法窄写入、猎手传播和历史独立；隔离界面覆盖自动默认、个人模板、取消、失败重试、轮询、窄屏。发布桌面 v0.2.87，并更新服务器容器。
