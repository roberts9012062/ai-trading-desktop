# 恢复完整桌面工作区

原页面与懒加载路由仍在源码中。Go 登录跳转到独立托管页，该页未嵌入主布局；原主布局又受旧 JWT 启动门和 /me 校验约束。恢复完整客户端，不改变后端仅负责任务托管的范围。

1. 让经过本次启动验证的 Go 服务器或中心单机会话进入原主布局；登录默认进入工作台，侧栏补充任务托管入口。
2. Go 会话不伪造旧 JWT，不授予原后台管理员权限。保留当前本地配置和旧账号存储；首次使用创建独立、稳定的本地配置命名空间。
3. 旧服务的 401 只影响对应功能，不登出有效的 Go 连接。旧账号资料读取和本地设置保留；Go 身份不自动调用旧 /me。
4. 不自动启动旧独立交易执行器。旧任务创建和重新执行入口在 Go 会话下明确指向 Go 托管；单机不新增任务，不自动重发金融动作。
5. 托管页保留现有 Go 同步、迁移、原生 worker 与执行权校验。断开和切换须等待本机 Go worker 的原生退出流程。
6. 验证启动门/同一进程恢复/新进程重登、完整导航和路由、原资料保留、旧 401 隔离及禁止旧执行器启动；隔离浏览器验收后推送、签名打包并更新既有发布清单。
