# 创建任务直接使用账户预算

用户要求：所有任务创建取消任务资金仓输入；普通止损亏损比例默认留空。

- AI 实时、AI 预测、量化、Jev、组合因子、克隆和收藏创建统一提交 allocated_capital=0。桌面 API 入口也固定此值，避免未填写额度的入口继承服务器旧默认值。
- 逐仓／全仓、每笔保证金、杠杆、资金使用比例、风格和持仓限制继续生效。新建任务不划转资金仓；每次下单按实际可用保证金检查。
- 服务器接受显式 0，AI／Jev 获得账户可用预算上下文，预测条件单也支持此预算模式。已有正额度任务保留原资金仓与流水规则；编辑任务不隐式改写额度。
- 猎手创建不再要求策略资金。服务器以创建时可用保证金作为风险计算基准，挂载时继续检查实际可用资金。
- 普通 loss_pct 为空时提交 null。克隆保留用户明确设定的止损；模型止损、预测结构止损和兜底止损保留。历史／合成回测的普通亏损比例默认也为空，回测初始本金仍保留。

验收：桌面端 81 个测试文件、690 项通过、1 项 GPU 跳过；TypeScript 检查及生产构建通过。服务器相关回归 199 项通过、1 项跳过。新增隔离 ORM 测试覆盖创建不划款、AI／Jev 不补回额度、猎手按可用资金初始化、OKX 原生预测单的账户预算与零可用拒绝。

scripts/account-budget-ui-preview.html 使用实际创建组件及隔离 API。Edge 自动验收量化、AI 实时／预测、猎手：没有资金仓控件，普通亏损比例空白，提交额度为 0／猎手不传 capital，保留保证金模式和每笔保证金。没有创建真实任务或订单。

发布版本：v0.2.104。服务器须先支持 allocated_capital=0，再发布桌面端。
