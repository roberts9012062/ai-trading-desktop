# 因子质量补全与小范围技术候选

目标：修复公式定义与执行缺口，允许验证少量新假设；不以特征数量或训练收益作为晋级标准。

## 本次范围

1. 模板名称与运行时特征表统一。旧手写索引把 OI_CHG/OI_PV/SKEW20 指向了其他行，改为从 FEATURE_NAMES 生成；旧持久化 token 不迁移。
2. 注册表补齐既有 59–61 三个永续结构特征、vol_scale 和 snr 算子族。
3. 仅追加 MACD_HIST(62) 与 KDJ_J(63)。服务器对应 83/84。CPU、CUDA、短线实时 TS、服务器执行保持同一定义。
4. 新候选默认不进入随机搜索或 LLM 词表；显式 search_feature_ids 或 seed_tokens 才允许纳入。增强短线的既有特征池不扩张。

## 定义与兼容

- MACD：SMA 初始化 EMA(12/26)，DEA 为 EMA9（DIF 出现前输入 0，与图表一致）；柱为 2×(DIF−DEA)/close。
- KDJ：RSV9，K/D 递归权重 1/3，初值为首个 RSV，J=3K−2D；原始值为 (J−50)/50。
- 两者再做固定 200 根因果 zscore，截断 ±5。首个可用位置分别为 224、207（从 0 开始）。矩阵保留预热 NaN，可用性检查拒绝中间缺口。进入算子时仅把这两个新行的合法预热前缀置 0，避免 cumsum 被 NaN 永久污染；评分仍按预热截取。
- 旧 0–61 行、算子 64–114、短线 token 115–122 含义不变。短线矩阵行按基础特征数动态定位，由 62–69 移到 64–71。
- 单独的桌面 36+ 特征映射为服务器 v3 时追加两次 NEG（恒等运算），使服务器能识别版本；含 v3 算子的输入保持幂等。
- 注册表只追加定义，保留既有 registryVersion，避免旧 AST 哈希失效；registryHash 随完整内容更新。
- RSI14 保留原滚动均值定义并明确标注，避免静默替换为图表 Wilder RSI。现有 DEV 已覆盖布林偏离家族，本次不增加重复的布林变体。分时线属于展示，订单流/成交量等才是可检验输入。

## 验证与晋级

旧特征逐行对拍、因果前缀不变、价格尺度不变、数据缺失拒绝、平滑后信号非常数、CPU/CUDA/TS/服务器对拍。真实数据先训练排序，再验证选择，最后展示封存段；按下一根开盘成交，计手续费、滑点及永续资金费率，同时报告双倍成本。

四组有限候选试验没有观察到新增技术公式的增量价值，因此本次不新增默认模板、不提高采样权重、不自动挂载实盘。结果见 [实验说明](../factor-quality-2026-10-12.md)。后续晋级还需未使用的新时间段、多币种、多市场状态和既有 walk-forward/相关性/成本门槛，不能反复用本次封存段调参。
