# M3 G5 长跑验证

使用真实默认后端工厂、sidecar IPC 和 IndexedDB，交替完成因子实验室和超级因子的独立任务。每个任务固定 ETHUSDT 15m 70,174 根、种群 3000、100 代；预先声明种子为 42 + 任务序号。每次创建新任务，不用上次任务的封存表现选种、重排或补选。

累计真实代计算时间至少 8 小时。启动自检、数据加载和任务间整理时间不计入这 8 小时。默认工厂的共享进程只启动一次，出现崩溃、自动重启、降级、暂停、失败或冠军证据不合格立即失败。两个入口都必须完成至少一项任务。

每代向控制器写进度日志；每项任务完成后写独立结果，重新核验合格冠军门。nvidia-smi 每 200ms 采样，另记录 sidecar 常驻内存和系统可用内存。结束后复核源码哈希，保留完整报告。短跑只诊断脚本，不声称通过 G5。

该浏览器测试使用 Python 命令监督适配器管理真实子进程。Rust 握手/生命周期由独立测试覆盖；本脚本不声称测试了正式安装包。

## 产品修订（2026-09-29）

产品批准将累计真实代计算时间从 8 小时缩短为 **4 小时**（约 700+ 任务、7 万+ 代）。
全部其余验收条件不变：0 崩溃/自动重启/降级/意外暂停、两入口都完成任务、
单一共享进程持续服务、冠军按冻结门复核、nvidia-smi 与内存采样、源码哈希复核。
报告同时保留 `G5_eight_hours_complete` 字段如实标注 8 小时口径未达成，不得混淆。
