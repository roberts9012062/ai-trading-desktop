# AI 预测交易

创建 AI 交易增加「实时交易 / 预测交易」，默认实时，旧载荷及引擎保持原样。预测模式复用 AI 看盘主播的模型、品种、多周期（最多三个）、K 线根数、分析间隔、技术线、方向偏好、操盘策略、短中长线设置，不调用语音、不占用主播任务。保证金、1–50 倍杠杆、逐仓/全仓、锁利沿用交易任务设置。

预测任务执行一个完整交易周期：分析观望 → 等待进场 → 确认成交 → 持仓保护 → 确认平仓 → 结束。首次预测及后续周期分析使用主播提示词和指标组合；预测 JSON 必须包含合法有限正数的进场、止盈、止损和允许方向。空仓可调整计划，持仓不反手、不加仓；用户明确选择持仓止损只允许收紧。模型失败或无效输出保留原有效保护，不生成假预测。

用户明确选择 OKX 原生条件进场单，附带止盈止损，服务器重启和桌面关闭不会撤销保护。条件单的原生 ID、客户端 ID、凭证模拟标记和任务归属持久化；提交前保存意图，超时先查询，不能重复提交。条件单触发生成的普通订单经交易所查询映射为原有成交镜像。改单与撤单必须再次核对是否已触发；先确认旧单撤销才能创建新的方向。已成交部分不得当作空仓。用户暂停/停止取消未成交进场单，已有仓位原生保护保留；强制平仓经现有接口确认。

止盈止损按周期修改原生保护单，只在交易所确认成功后更新显示线。停止及自然结束以官方成交和仓位归零为准，不能根据瞬间无持仓推测结束。锁利和用户兜底风控仍可优先平仓。所有实盘请求经 services/live_trading 和交易所适配器；不给其他交易所静默模拟能力。

任务卡增加「查看」，打开浮动 K 线窗口：持续刷新形成中的蜡烛，显示当前有效进场、止盈、止损线；确认成交后进场线变为持仓均价线及浮盈。AI 看盘主图显示同品种预测任务的有效线，多任务标签含任务名，结束后清理活动线。首次还没有有效预测时显示等待，不画示例交易线。

验证覆盖方向与价位、只收紧止损、模型异常、条件单超时/重启、部分成交、撤单成交竞态、动态修改失败保留原保护、实际平仓后单次结束、暂停/停止、模拟凭证、原有实时交易回归，以及真实页面的创建切换、浮窗和 AI 看盘画线。验收使用离线模拟适配器，不提交生产测试订单。

实现细节：移动进场价时先确认撤单，再按固定保证金重新计算数量挂单；同进场价只修改附带保护。改单后读取交易所实际价格确认，回执本身不能用于更新 UI。条件单生成普通订单后以实际成交量管理仓位；部分成交先撤销余量，再挂独立 OCO。确定性保护单客户端编号用于重启恢复，持仓暂时不可见不代表平仓完成。

预测分析、浮窗、选中预测任务的 AI 看盘主图统一使用服务器转接的 OKX K 线，避免客户端域名解析问题和不同交易所价格混用。普通任务继续使用既有行情图。预测行情短缓存 3 秒，图表 3 秒刷新、服务器约 5 秒检查原生单，AI 按配置的 5–30 分钟分析。原生进场及附带保护在交易所运行，服务器负责修改、对账及闭环。

验证记录：桌面 TypeScript 检查、生产构建通过；658 项前端测试通过，1 项既有 GPU 检查跳过。新增服务器预测专项 38 项通过；服务器全量回归为 1619 通过、68 个既有失败、3 跳过，失败名单与原版逐项一致。后续专项包含新增行情代理与权限检查。浏览器使用真实创建面板、任务卡及图表，验证创建载荷、动态蜡烛、成交后均价与盈亏、止损线更新、图表不重建及结束后清线。未提交生产验收订单。

原生接口依据：[OKX API 文档](https://www.okx.com/docs-v5/en/)中的条件单、附带止盈止损、查询及改单接口；[更新记录](https://www.okx.com/docs-v5/log_en/)中的 Trigger order 附带保护改单参数。
