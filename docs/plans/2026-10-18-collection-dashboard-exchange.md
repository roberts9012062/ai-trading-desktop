# 工作台与交易所接入统一到 API VALUE COLLECTION

范围：加密货币；在 v0.2.203 的行情接入基础上覆盖工作台金融数据与交易所连通验证。

- 工作台：自选报价、账户权益/保证金、持仓、最近成交、账单与收益分析、实际通道状态。
- 交易所接入：展示接口中心 Key 与私有能力、保存现有加密交易所凭证、通过接口中心验证账户连通。
- 传输：账户与订单复用已鉴权的桌面 RPC、业务签名及字段归一化；所有收到的 OKX 签名请求兑换中心一次性票据，再 POST 固定 /edge/okx。公共 instruments/time 补齐白名单。桌面收益分析保留原生密封凭证与完整账单分页，在原生进程签名后走中心票据，Secret 不进入页面；中心模式不走旧代理或服务器 HTTP 兜底。
- 私有推送：中心 /edge/okx-ws，45 秒后重新签票及重新获取登录签名。账户/持仓/普通订单共用一条连接，条件单保留低频账户校验，结合现有公共流和 HTTP 预留控制并发。
- 数据边界：业务服务保留登录、用户凭证加密保存、自选成员、AI 任务元数据和归属；实时金融数据来自接口中心。Secret 不发送给接口中心；签名和票据不进入持久化缓存。
- 权限：仅为用户指定测试 Key 的有效授权添加 okx_private、okx_private_ws，不改套餐或其他 Key；记录授权审计。
- 验证：传输字段和签名保持、错误不回退旧线路、写请求不重发、私有 WS 登录成功后再订阅、账户/Key 切换隔离、工作台首次报价及 UI；真实公共接口与私有网关验收。没有调用方凭证时不宣称真实账户或交易验收。
- 交付：版本 0.2.204，推送 GitHub 并触发签名安装包，验证发布清单。
