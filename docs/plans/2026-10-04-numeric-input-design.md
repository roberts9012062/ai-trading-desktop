# 数字输入编辑

所有数字输入框共享字符串草稿。可以删除到空白、重新输入、粘贴、小数和负号；输入过程不回填默认值、不把草稿钳制到最小值。公共 Input 的 number 分支和页面原生数字框共用 NumericInput，文本、密码、复选框、滑块保持原行为。

完整合法的草稿才交给原有业务回调，以保持计算预览；未完成或不合法的草稿独立保存，离开输入框才显示错误，提交时报告错误并阻止使用旧数值。交易所、资金、杠杆和整数参数的实际限制在完成校验中保留。可选止盈止损、配额覆盖和注明留空使用默认规则的字段继续允许留空。

创建、保存、下单、挖掘、筛选按钮显式接入数字校验，作用域为当前编辑区、表单或弹窗。取消、关闭和恢复默认不受提交校验拦截。恢复默认同时清除输入草稿，即使业务默认值与清空前的值相同也可恢复。

验收包括真实保证金组件、指标周期组件、公共与原生框：清空不回填、删除重写、小数/负号/0、上下限、必填/可选、拒绝旧值提交、取消、同值恢复默认、Enter 和原生表单提交。运行整个桌面端测试、类型检查和生产构建后发布补丁版本。
