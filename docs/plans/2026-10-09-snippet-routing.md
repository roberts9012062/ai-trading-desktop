# Snippet 默认路由与服务器容灾

用户确认：停用全市场常驻行情/K线刷新、新闻等后台展示服务，保留挂任务所需行情/风控、用户/全局管理和按需兜底接口。

- 全局 `server_market_enabled` 默认 false：桌面公共 WS/REST、私有 REST/WS 优先 Snippet；true 强制服务器并恢复常驻展示后台服务。桌面定期读取配置，服务器每次操作再次检查。
- 保留现有 `/api/live/*` 权限、交易校验、规范符号/张数换算和镜像。桌面通过认证 RPC 通道执行这些现有 API；OKX 适配器在请求上下文内把短效已签名报文交给桌面，经固定 Snippet 域名发送。Secret 永不下发，不创建通用签名/任意 URL 代理。
- 私有代理结果不写入任务共享缓存。交易写请求不自动重发，服务器直接对账验证结果；网络结果未知时提示先查询订单。只读请求失败、429 或断线可经服务器兜底，熔断后冷却再试。
- 桌面私有 WS 使用服务器签发的短效登录证明，账户/持仓/订单推送只触发合并刷新，不把浏览器原始数据注入服务器任务状态。退出/切换路由/换账号时关闭连接和定时器。
- 历史 REST 通过桌面缓存、请求合并、限流退避减少共享出口压力。429 立即回退，不承诺重写 Snippet 可以改变出口 IP。公共 REST 复用现有私有 REST 域名；2.1 线上实测缓存 PUT-ERROR、12/19 成功、零 HIT，边缘缓存尚未通过验收。
- 服务器保留交易前校验、写请求的权威回读，以及订单镜像/盈亏的权威对账；这些数据不接受桌面回传原始数据写入。条件保护单及资金/账户设置等未转发写能力继续走服务器。
- 服务器默认不启动全市场 WS/REST、forming 对账和新闻循环；只刷新任务/保护持仓所需品种。桌面兜底按在线订阅按需取数，不停用任务风控。
- 验证：权限隔离、路由开关、GET 容灾、POST 不重放、缓存隔离、WS 生命周期；类型检查/构建；线上模拟盘验证；两仓提交推送、Docker 部署、桌面 v0.2.156 签名发布。
