# Snippet 自动线路池 · v0.2.170

管理员后台 /admin/snippets 配置 REST、公共 WS、私有 WS 代理。登录后服务器使用 Redis Lua 按在线人数/权重原子分配，用户固定在线路上；短时间重登保留原线路；断线 90 秒后释放在线名额。

桌面每 30 秒续租，新增线路不打断健康连接；停用、探测隔离或本地连接失败后切换。公共及私有 WS 保留现有连接复用、心跳、退避；更换端点先关旧连接，再随机延迟重连。REST 交易写操作不会因线路变化重发。

所有地址从经过认证的产品服务器获取。Rust 原生收益模块自行获取可信分配，renderer 不提供任意目标地址；凭证、产品 token 不向公共行情代理发送。管理员只能添加公网域名 origin，服务端只读探测固定 DNS 解析结果并禁止重定向。

服务器配置保存在 PostgreSQL，Redis 负责低成本分配、续约和聚合采样。服务端轻量健康检查最多每轮三个端点，客户端错误只影响自己的线路，不会让一个用户隔离全体用户。429 作为限流统计，不将账户级额度问题误判成代理死亡。

验证：真实 Redis 1000 个合成账号并发分配三条等权线路，人数 334/333/333，用时 0.726 秒；重复并发登录不增加人数；权重 1:2 为 100/200；验证禁用迁移、故障排除、容量上限和过期清理。此项只证明分配层，不代表 1000 个真实 OKX 账户的长期吞吐。

发布时保留原有三个默认代理，新增线路默认停用，管理员部署对应 Snippet 并测试后启用。用户需更新 v0.2.170 才参加自动分流；旧客户端保持固定地址，不在租约统计内。
