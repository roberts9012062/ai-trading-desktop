# OKX 桌面备用历史下载源

用户要求增加备用下载源并集成本地桌面端。现有桌面已支持官方 ZIP 归档，以及用于归档交叉校验的 OKX history-candles / Snippets 公共通道。GitHub 下载器也依赖官方数据，额外引入 C++ 侧车不能提供独立数据。因此复用现有受信任公共 REST 通道，扩展为完整日数据下载备用源，无新增本地服务和依赖。

统一渠道选择器增加 K 线下载方式：自动（默认）、仅归档、历史接口备用。选择保存在本机，每次取数开始时冻结。本次只扩展 K 线；资金费率与逐笔继续原归档流程，缺失仍明确标记。

自动模式优先归档；网络故障或日归档未发布时使用备用接口。月包网络故障后降为逐日备用，避免重复下载故障月包。内容校验错误继续失败。归档内缺失分钟仅在备用日完整且所有重叠分钟字段一致时修复。

备用按北京时间日、1m、100 根分页，限速/重试/取消复用现有实现。严格校验收盘状态、分页推进、单位、完整 1440 分钟；不合成 K 线，不混用其他交易所。完整日与分页独立缓存，记录来源和线路；缓存再次读取也校验。沿用完整分钟聚合和原过拟合验证。

验证：备用切换、强制来源、缓存、缺口/冲突、坏包、分页、取消及限流回归；真实 ADA 缺口日与归档对照；界面选择和持久化；类型检查、构建、GitHub 发布 v0.2.187。服务器代码未变更，无需重建 Docker。
