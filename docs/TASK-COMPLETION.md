## 📋 实现细节

### 1. 高级参数面板

**位置**：配置参数卡片下方，可折叠设计

**6 个可调参数**：

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| 种群规模 | 300 | 50-30000 | 每代个体数量，影响搜索广度 |
| 进化代数 | 30 | 10-3000 | 迭代次数，影响搜索深度 |
| 最大深度 | 5 | 3-8 | 公式复杂度限制，防止过拟合 |
| 训练集比例 | 0.7 | 0.5-0.8 | 训练/验证分离，保留验证数据 |
| WF 验证折数 | 3 | 2-5 | Walk-Forward 折数，时间序列验证 |

**功能特性**：
- ✅ 折叠/展开动画（三角箭头旋转 90°）
- ✅ 参数自动验证和裁剪（超出范围自动限制）
- ✅ 一键恢复默认值按钮
- ✅ 禁用状态处理（挖掘进行时不可修改）

### 2. 挖掘进度增强

**问题诊断**：
- 原版只显示简单的百分比和代数
- 长时间运行时用户以为程序假死
- 缺少预计完成时间

**解决方案**：

#### A. 详细进度信息
```
第 15/30 代 · 适应度评估中 · 52.3% 完成
```
- 显示当前代数和总代数
- 百分比精确到小数点
- 状态文本描述当前阶段

#### B. 视觉状态指示
```
● 正在进化中...
```
- 绿色脉动圆点（CSS 动画）
- 实时更新状态文本
- 视觉反馈"程序还活着"

#### C. 参数信息卡片
```
┌─────────────────────────────────────────┐
│  当前代数: 15 / 30    种群规模: 300    │
│  最大深度: 5          WF 折数: 3        │
│  ● 正在进化中...      预计剩余: ~3 分钟 │
└─────────────────────────────────────────┘
```
- 4 个关键参数一目了然
- 预计剩余时间（基于平均每代耗时）
- 网格布局，对齐清晰

#### D. 进度条优化
- 从 50% 开始（前 50% 为回填阶段）
- 平滑过渡动画（500ms）
- 青蓝→翡翠绿渐变

### 3. 防过拟合说明

**展开高级参数时自动显示**：
```
防过拟合机制：Walk-Forward验证（3折）确保因子在未见样本上稳定；
训练集比例70%保留充足验证数据；最大深度5限制公式复杂度。
种群规模和代数平衡搜索广度与深度。
```

## ⚠️ 注意事项

### 性能警告
- 种群 >5000 会显著增加计算时间
- 代数 >500 可能需要数小时
- 极端配置（30000×3000）需要 >16GB 内存

### 使用建议
1. **首次测试**：使用默认值（300×30）
2. **深度搜索**：种群 1000-3000，代数 50-100
3. **防过拟合优先**：增加 WF 折数到 5，降低最大深度到 4

### GPU 推荐
- 种群 <1000：CPU 可接受
- 种群 >1000：强烈推荐 GPU
- 种群 >5000：必需 GPU
