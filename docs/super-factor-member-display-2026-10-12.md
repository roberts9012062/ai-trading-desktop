# v0.2.178：回捞组合通过后成员未显示

用户报告原生 GPU / SOL / 15m 任务显示「★ 超级因子」，4 个成员、平均绝对相关性 0.366、封存段 14035 根、等权 Sortino 1.89、2× 成本 Sortino 1.08，下面的冠军列表却为空。

## 原因

组合可以从失败的单因子候选中回捞成员，再独立评估组合。组合通过不等于各单因子分别通过。原生引擎正确返回 `portfolio.members` 与 `super_passed=true`，但页面只用严格合格的 `champions` 渲染表格，`superMembers` 只为已有行加标记。所有成员未单独合格时，成员无行可显示。

原生 runner 已持久化组合 tokens，但只持久化合格/研究级单因子的公式。因此旧任务可恢复组合 tokens，无法凭空恢复当时未保存的公式或淘汰原因。

## 修复

- 因子实验室和超级因子共用的组合卡片增加独立成员区域，按实际 `portfolio.members` 顺序列出所有成员及 tokens，支持复制完整成员 tokens 数组。
- 新任务在原生结果进入 runner 前，按 tokens 从合格、待验收、拒绝候选中提取成员公式和单因子资格，附在组合结果中持久化。只捕获组合实际成员，不扩大冠军列表。
- 旧任务无需重新挖掘：打开已完成任务即可查看已有 tokens。没有公式、资格元数据时不编造这些字段。
- 已通过组合而单因子列表为空时，明确提示查看组合成员。
- 保留原有组合通过条件、封存边界、研究级分类、单因子冠军计数与挂载资格判断。
