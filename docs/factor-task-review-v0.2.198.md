# v0.2.198 因子任务复审

因子进化页面选择普通因子任务后，新增“任务因子复审”：可查看真实完整交易轮次净额、刷新同源健康指标，以及运行 7/14/30/60 天当前规则的历史情景回放。实际成交和历史模拟独立列示，费用、资金费率缺口、过期数据和 OHLC 路径差异明确展示。

纯因子任务的进化替换新增当前版本任务规则预筛及相对原式改善证据要求。旧作业缺少证据时须重新研究；周期 OHLC 预筛仍不能代替分钟或逐笔验收。此版本不会凭回放结果自动改变任务公式、止损、仓位或运行状态。

服务器本轮以冻结数据及固定预算评估 68 个候选，没有选出同时满足训练与验证双倍成本盈利条件的替代式。分钟情景显示原始信号与完整风险规则存在显著交互，需要继续检验信号周期和风险尺度的匹配；不能据此简单断言所有因子没有价值或取消保护规则。

验证：相关桌面 Vitest 9 个文件 / 30 项测试通过，TypeScript 检查与 Vite 生产构建通过。Edge 浏览器验证健康刷新、14 天回放请求、1200/480 像素布局及无页面横向溢出；后端相关回归 174 项通过，真实冻结研究重跑结果一致。发布沿用 GitHub 签名 Windows 安装包流程。
