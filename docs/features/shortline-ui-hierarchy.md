## 状态流转

```
[idle] 空闲状态
   ↓ 点击"一键启动挖掘"
   
[backfill] 回填数据
   ↓ 进度 0-40%
   │ 回填 2024-04-01 · 128.5 MB
   
[mining] 挖掘因子
   ↓ 进度 40-100%
   │ 第 15/30 代 · 适应度评估中 · 52.3% 完成
   │ ● 正在进化中... 预计剩余: ~3 分钟
   
[completed] 完成
   │ ✓ 完成：发现 5 个冠军
   
[failed] 失败
   │ ✗ 失败：[错误信息]
```

## 颜色分层

```
层级 0 (最深)：#05070C - 页面背景基础
层级 1：      #0A0D12 - 渐变起点
层级 2：      #0F131C - 输入框、内层卡片
层级 3：      #161D2B - 渐变中间
层级 4：      #1E2636 - 主卡片背景

强调色：
- 主色：#38BDF8 (青蓝) - 按钮、聚焦、进度条起点
- 次色：#6EE7B7 (翡翠绿) - 进度条终点、状态指示
- 警告：#E9A568 (琥珀) - （暂未使用）
- 错误：#EF4444 (红) - 错误提示、停止按钮

文本层级：
- 主标题：#FFFFFF (白色)
- 次要文本：#D1D5DB (#gray-300)
- 辅助文本：#9CA3AF (#gray-400)
- 禁用/弱化：#6B7280 (#gray-500)
- 极弱提示：#4B5563 (#gray-600)
```

## 交互反馈

### 输入框
```
默认状态：border-white/10
悬停状态：border-white/15
聚焦状态：border-[#38BDF8]
禁用状态：opacity-50
```

### 按钮
```
主按钮（启动）：
  bg-gradient-to-r from-[#38BDF8] to-[#6EE7B7]
  shadow-[#38BDF8]/20
  hover: shadow-[#38BDF8]/40

次要按钮（停止）：
  text-red-400 border-red-500/30
  hover: text-red-300

辅助按钮（重置/恢复）：
  text-gray-400 border-white/10
  hover: text-gray-300 border-white/20
```

### 进度条
```
背景：bg-white/5
填充：bg-gradient-to-r from-[#38BDF8] to-[#6EE7B7]
动画：transition-all duration-500
```

### 折叠面板
```
触发器：▶ 三角箭头
展开状态：旋转 90° (transform rotate-90)
动画：transition-transform
```

## 响应式布局

### 桌面 (md+)
- 参数表单：3 列网格
- 高级参数：3 列网格
- 冠军卡片：单列（宽度充足显示完整公式）

### 平板/手机
- 参数表单：单列堆叠
- 高级参数：2 列网格
- 最小边距：16px (p-6)

## 无障碍设计

- 所有输入框有 label
- 禁用状态明确（opacity + cursor）
- 颜色对比度符合 WCAG AA 标准
- 状态变化有文本提示，不仅依赖颜色
- 进度条有百分比文本
