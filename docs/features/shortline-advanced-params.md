# 短线因子实验室 - 高级参数设置

## 功能概述

短线因子实验室现在支持高级参数设置，用户可以自定义挖掘参数，同时增强了挖掘进度显示，避免"假死"感。

## 新增功能

### 1. 高级参数面板（可折叠）

**默认值设计**：
- 在用户不改变任何参数的情况下，系统使用优化的默认值
- 默认参数平衡了搜索效率和防过拟合能力

**可调参数**：

| 参数 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| **种群规模** | 300 | 50-30000 | 影响搜索广度，越大搜索越全面但越慢 |
| **进化代数** | 30 | 10-3000 | 更多代数=更深搜索，但时间更长 |
| **公式最大深度** | 5 | 3-8 | 限制公式复杂度，防止过拟合 |
| **训练集比例** | 0.7 | 0.5-0.8 | 70%训练/30%验证，保留充足验证数据 |
| **WF 验证折数** | 3 | 2-5 | Walk-Forward 折数，防过拟合关键参数 |

### 2. 防过拟合机制

**Walk-Forward 验证**：
- 默认 3 折时间序列验证
- 确保因子在未见样本上稳定

**训练集/验证集分离**：
- 默认 70/30 比例
- 保留充足的验证数据

**公式复杂度限制**：
- 默认最大深度 5
- 避免过度复杂的公式

### 3. 增强进度显示

**挖掘阶段详细信息**：
- ✅ 当前代数 / 总代数
- ✅ 种群规模显示
- ✅ 最大深度显示
- ✅ WF 折数显示
- ✅ 实时状态指示器（绿色脉动点）
- ✅ 预计剩余时间
- ✅ 百分比进度（精确到小数点）

**状态文本**：
```
第 15/30 代 · 适应度评估中 · 50.0% 完成
正在进化中... 预计剩余: ~3 分钟
```

### 4. 一键恢复默认值

点击"恢复默认值"按钮可快速重置所有高级参数为推荐值。

## 使用场景

### 场景 1：快速测试（使用默认值）
1. 选择币种、周期、算力
2. 直接点击"一键启动挖掘"
3. 系统使用 300 种群 × 30 代的默认配置

### 场景 2：深度搜索（自定义参数）
1. 展开"高级参数设置"
2. 调整种群规模到 1000
3. 调整进化代数到 100
4. 点击"一键启动挖掘"

### 场景 3：防过拟合强化
1. 增加 WF 折数到 5
2. 降低最大深度到 4
3. 提高训练集比例到 0.75

  ? (activeTask.current_generation / activeTask.generations) * 100

## 防假死设计

**问题**：挖掘过程可能持续数分钟，用户容易误以为程序卡死。

**解决方案**：
1. **详细进度信息**：显示当前代数和百分比
2. **实时状态指示**：绿色脉动点表示活跃
3. **预计剩余时间**：给用户心理预期
4. **平滑进度条**：视觉反馈持续更新
5. **状态文本更新**：每代更新一次

## 版本兼容性

- 最低 Node.js 版本：18.0.0
- React 版本：18.x
- TypeScript 版本：5.x

## 注意事项

1. **种群规模和代数**：设置过大会显著增加计算时间
2. **GPU 必需**：大种群规模（>1000）建议使用 GPU
3. **内存占用**：种群 30000 × 代数 3000 可能占用 >16GB 内存
4. **过拟合风险**：最大深度 >6 容易过拟合
