# v0.2.200 基础特征数量与论文配方入口修复

参与挖掘列表中的 64 项是底层特征，不是候选公式总数。v0.2.199 新增六类、十二个方向的论文启发组合配方，使用现有特征和算子，基础特征数量没有增加。本版明确分别显示“基础特征（64/64）”和“论文研究配方 · 6 类 / 12 个方向公式”，可展开查看每类依赖及未选中的基础特征。按用户选择可构造的配方数与训练数据实际可用性分别说明。

排查同时发现三条实际漏接：普通挖掘的 `buildSearchConfig` 丢失论文开关；超级因子表单未收集和传递开关；CPU 单 worker 载荷和多核初始种群也未接入开关/配方。本版补齐这些路径。新建两个入口都默认启用，可取消；旧任务未设置开关时保持原有关闭行为。开启论文研究的加密任务使用既有因果研究模式，仍按训练特征能力过滤，保留用户种子优先及额外种子配额限制。

回归覆盖普通入口到原生请求、超级因子表单到创建配置及保存状态、CPU 单进程实际启动载荷，以及 CPU 并行评估确实包含论文配方。相关 14 个文件 / 67 项测试通过，TypeScript 检查及 Vite 生产构建通过。Edge 中操作实际两个表单，确认开关开/关均传入提交配置，并验证 1200/480 像素布局、六类配方列表、基础特征计数与无页面横向溢出。

此版修复桌面接线及展示，不改变特征 ID、数值内核、已有实盘公式或风险参数；没有把组合配方冒充新基础特征。
