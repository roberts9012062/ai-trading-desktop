# v0.2.203 · 实时 K 线与加载速度修复

接入数据中心后，首屏曾串行等待六个周期的历史请求，可见图表订阅也可能在加载超过 30 秒或切换合约后被旧订阅挤占。现在只请求当前周期，关闭邻合约及日线后台预取；图表挂载期间持续持有实时订阅，切换后立即释放旧订阅，并优先分配当前图表的连接额度。切换列表内合约时复用原报价连接；45 秒行情票据正常续期不再强制重拉整段历史。

修复实时尾部跨分钟后反复向图表回写旧 K 线的问题：Lightweight Charts 会拒绝早于已绘制末根的增量写入，导致新 K 线也无法绘制。现在增量写入从图表当前末根开始，历史与完整尾部继续用于指标计算。

合约目录、搜索及列表报价使用同一套 60 个 OKX USDT 永续合约。BTC、ETH 等常用合约优先，从交易所当前有效目录中选取，避免订阅全部合约。

接口中心配套更新 `5285fbd` 已部署到 193.122.234.104：最新 240 根 K 线一次读取，共享代理返回 429 时对固定的 OKX 官方公开行情接口做一次回退。历史翻页保持有界；私有交易接口不参与回退。

验证：桌面端 1169 项测试通过、6 项按环境条件跳过；TypeScript 检查及生产构建通过。接口中心本地及服务器均 196 项测试通过，114 个源文件严格类型检查通过。

真实 Key 图表复测覆盖：60 个合约、首屏 240 根历史、BTC → ETH → SOL → BTC 切换、日线切换 1 分钟、跨分钟和 45 秒票据续期。复测入口为 `scripts/collection-chart-preview.html` 与 `scripts/verify-collection-chart.py`，通过环境变量 `COLLECTION_LIVE_KEY` 提供测试 Key；脚本不保存凭据。

本机部署后样本：首屏 3.88 秒，ETH 3.58 秒，SOL 5.85 秒，切回 BTC 缓存 0.05 秒。整个跨分钟及续期过程仅四次 240 根历史请求，另有一次三根恢复请求；未出现页面异常或旧数据回写错误。耗时受网络和上游负载影响。
