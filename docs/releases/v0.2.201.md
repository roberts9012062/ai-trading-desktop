# v0.2.201 · 加密货币行情统一接入

个人中心新增“数据配置”。用户在 https://lium.eu.org 获取自己的 Key，填写、检测并保存后，即可使用套餐允许的 OKX USDT 永续在线行情。

- 历史 K 线和分页、七周期实时原生 K 线、实时报价、五档盘口、最近成交与逐笔推送统一通过接口中心。
- 同一合约多个周期共用一条 WS；盘口和成交可合流。按套餐连接与订阅额度调度，保留 HTTP 取数连接，流到期重新签票。
- 明确区分基础币成交量、合约张数、成交额及收盘确认；同毫秒不同成交按交易所 ID 保留。
- Windows 使用系统 DPAPI 加密保存 Key，按账号和业务服务器隔离。业务登录、账户通知及交易所下单凭证保持独立。
- 不复用旧线路的在线 K 线持久化缓存；配置接口中心后，公共行情失败不会静默回退至旧公共代理。
- 长期研究归档、回测及服务端托管任务仍沿用其独立的数据路径与授权。

验证记录（2026-10-18）：接口中心 195 项本地及服务器回归通过，114 个 Python 源文件严格类型检查通过；桌面全量 1161 项测试通过（6 项按条件跳过），TypeScript 检查、前端生产构建及 Rust DPAPI/地址边界测试通过。真实 Key 验证了 BTC/ETH/SOL 最近成交、盘口快照、七周期 K 线，以及超过 45 秒后的票据续签。配置页面通过无效 Key、检测、保存、脱敏输入与额度显示检查。

公共最近成交只覆盖上游可查询窗口，不保证完整成交带；断线缺口和未授权能力会明确显示。
