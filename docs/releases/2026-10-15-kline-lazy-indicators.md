# v0.2.197：修复 K 线历史懒加载后指标丢失和错位

拖动 K 线查看历史、十字线仍停留在图上时，补入旧 K 线会重排共享时间轴。
lightweight-charts 在各条 series 的批量写入中途同步做十字线命中检测，
此时部分指标视图仍缓存旧逻辑索引，抛出 `Value is null`。
原有失败处理随即清空均线，并让 MACD 等副图停留在旧历史范围。

整批数据写入、series 重建和实时全量自愈前，现在先解除旧十字线命中。
全部蜡烛和指标写完后，鼠标移动即可正常恢复十字线；历史视口锚点保持不变。
不修改指标算法、周期参数和行情数据源。

浏览器回归使用真实 React hooks、Zustand store 和图表库，覆盖：

- 1m、5m、15m、30m、60m、240m、1d。
- BTC 和 PEPE 价格量级，强弱指标 V1/V2。
- 连续 6 页历史（240 到 1440 根）、MA/MACD 数值、全部副图历史覆盖。
- 实时推送与历史加载交错、全量自愈、历史视口保持及更新后的十字线。

复现命令（先启动 `pnpm dev`）：

```powershell
python scripts/verify-kline-lazy-load.py --url http://127.0.0.1:5173
```

修改前的单场景回归出现 58 项数据/视口失败和 28 次图表错误。
修改后 14 个浏览器场景、84 页历史全部通过，另有 59 项相关 Vitest 测试、
TypeScript 检查和 Vite 生产构建通过。构建保留已有分包提示。

桌面版本升级至 0.2.197；本次没有服务端代码变更，无需重建服务端 Docker。
