# v0.2.204 · 工作台与交易所接入 API VALUE COLLECTION

工作台行情、账户权益与保证金、持仓、最近成交、账单和收益分析统一使用 API VALUE COLLECTION 的公共/私有数据通道。首次打开工作台即加载 60 个合约并订阅报价，无需先访问行情页。顶部显示实际中心行情状态和私有接口授权，停止查询旧行情渠道与国内期货信号入口。

交易所接入页展示中心 Key 的账户及私有推送权限；“测试连通”通过中心的 `okx_private` 票据实际查询已配置的 OKX 账户，不再调用旧连通检测。旧线路的检测状态不会被误当成新通道已验证。凭证保存、用户登录和 AI 任务记录由业务服务管理；交易所 Secret 不发往接口中心。

账户请求沿用业务签名和数量/订单字段归一化，底层请求通过 `/edge/okx`。连接失败、Key 权限缺失和代理错误明确报错，中心模式不静默降级到旧数据线路。写请求保持不自动重发。所有历史及账户 HTTP 共用排队槽，给行情和私有 WS 留出并发额度。

收益分析在桌面原生进程解密短期凭证、生成签名、经中心读取完整账单并保留分页完整性检查、缓存及账号隔离。日历、累计曲线、汇总与今日指标统一使用扣费及资金费后的净值，避免毛净混用或重复扣费。

私有账户、持仓和普通订单共用中心私有 WS，45 秒续期重新签票及获取登录签名。仅在 OKX 返回登录成功后订阅；网关就绪和心跳不冒充账户鉴权。正式与模拟账户分别路由，条件单另保留低频校验。

验证：前端 1181 项测试通过（6 项跳过）、TypeScript 检查、生产构建、Windows DPAPI 和原生签名/只读白名单测试；接口中心 199 项测试、114 个源文件严格类型检查，服务器部署后健康。真实测试 Key 验证私有 REST 票据和公开时间透传，以及正式/模拟私有 WS 网关心跳。

页面成功及权限不足路径使用隔离示例账户验证，入口为 `scripts/collection-dashboard-preview.html` 与 `scripts/verify-collection-dashboard.py`。本次未取得调用方 OKX 私有凭证，网关验收不代表真实账户鉴权或实盘交易已验收；用户可在升级后点击“交易所接入 → 测试连通”验证自己的账户。

仅对用户明确指定的测试 Key 增加 `okx_private`、`okx_private_ws`，未调整套餐和其他 Key。
