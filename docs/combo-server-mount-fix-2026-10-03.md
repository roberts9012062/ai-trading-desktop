# 组合因子统一挂载服务器

因子实验室与超级因子挖掘的组合任务不再创建后自动切换到本地引擎，单因子挂载也移除了这一无服务器实现的切换入口。创建成功提示说明任务由服务器运行，启动后不依赖桌面端开机。

创建与编辑 API 按任务类型检查每个组合成员：普通因子、AI 参考组合、决策模型的因子组合均检查实际数据依赖。Gate 研究来源、旧 local_only/research_only 元数据不决定服务器能力。AI 参考组合逐组转换 v3 编码，保持组合结构；决策模型组合按 decision_strategy.kind=factor 传递，避免组合参数被丢弃。

服务器 similarity 修正缺失数据对齐：保留各公式的原 K 线下标，使用公共有效时间段，只计算相邻实际 K 线的收益。修复旧实现过滤 NaN 后数组长度不一致及不同时间错配的问题。

数据边界没有伪造：QUOTE_ILLIQ20、LIQUIDATION_IMBALANCE、AVG_TRADE_QUOTE 的服务器直连数据尚未接入。涉及这些特征时，在创建前显示具体成员编号，不创建无法计算的任务，不自动改为本机执行。需要实际成员公式确认是否涉及这些输入，再补齐相应采集链路；目前不能宣称任意逐笔或强平因子均可实盘运行。

发布版本按用户确认的最新 v0.2.80 增加 0.0.1，目标 v0.2.81；Tauri 与 package.json 同步。用户已授权 GitHub 上传、触发签名打包，以及更新 64.83.17.130 的服务器容器。

验证：桌面端完整 Vitest 通过，TypeScript 检查及 Vite 构建通过；服务器因子、AI 交易、短线、模拟撮合、交易所、衍生数据及猎手相关回归 442 项通过。新增组合请求转换、三种任务组合能力检查、服务器相似度真实公式与缺失下标对齐回归。
