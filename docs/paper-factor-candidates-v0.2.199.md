# v0.2.199 论文因子研究种子

依据七篇经核对的近期原始文献，加入六类论文启发配方：流动性冲击反转、下行风险状态反转、低冲击状态动量、订单流价格残差、资金拥挤价格残差、主动成交冲击反转对照。每类包含相反方向，共十二个公式。

新建本地搜索默认勾选“论文与经济假设种子”，可取消作基线对照。新增种子仍按训练段真实特征能力过滤，沿用约 25% 的额外注入上限、用户种子优先及随机探索；CPU、原生 GPU、WebGPU 使用同一份带出处的清单。既有特征和算子 ID 不变。

这些公式是现有标准化特征上的改编，不是原论文横截面、多市场或双腿交易的完整复现。当前三个任务的冻结数据只支持三类价量配方，十八次任务候选评估没有选出训练与验证双倍成本同时盈利的替代式。订单流/资金特征缺失时不会以零或 K 线代理替代。预印本中短周期反转的负面成本证据也已登记；链上、精确十二小时交易时段与期现 carry 暂待数据或执行模型。

完整引用、公式和数据边界保存在随包分发的 `public/pykernel/factor_lab/paper_factor_catalog.json`，与服务器清单一致。新配方只进入研究池，实盘晋级门槛及现有线上任务配置保持原样。

验证：相关桌面 49 项、原生内核 18 项和服务器 77 项测试通过，类型检查及生产构建通过。Edge 中实际加载随包 Pyodide 和 JSON 后，核对十二个论文配方、十八个总实验配方与 TypeScript 一致。浏览器资源清单已补齐 JSON 及已有语义模块；原生版本为 `native-gpu-v1-m3.10-paper-seeds`。
