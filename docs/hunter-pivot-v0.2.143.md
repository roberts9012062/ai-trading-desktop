# 枢轴波段猎手 v0.2.143

## 用户要求与实现

新增独立的枢轴波段入口，趋势猎手V4、反弹猎手继续保留。固定60分钟K线，默认双向、50币，最多200币；每轮可批量挂载，最多同时10个已挂载、待成交、持仓子单。同币已有任务、持仓或待确认委托时不重复接管。完成或取消后释放名额；完成交易自动入历史。

参数表单和序列化复用量化交易的 `swing_pivot`。默认左3、右3、盘中预确认1、多空交替、最小幅度1.5%、ATR倍数1.5、ATR周期14。服务器复用量化的 `compute_swing_pivot_signal`，保留盘中K线、240根信号窗口及最近2根K线的新鲜度限制。以真实枢轴时间与方向标识信号；挂载与下单前均复核。右侧正式确认参数大于2时，正式信号可能已超过入场窗口而被跳过，盘中预确认仍遵循用户设置。

锁利润强制开启，默认自动模式。支持调整阈值和模板，后台及实际执行均保证开启。沿用保证金ROI兜底止盈/止损，提交保护止损，入场枢轴极值失效或出现反向枢轴也会全平。本策略不滚仓。锁利平仓后的信号冷却按币种传递给后续子单，重复信号不重复计数。

同账户、同交易环境下，枢轴交易按币种多空合计累计当日净亏损完整交易，盈利不清零；2次后只屏蔽该币种的扫描、挂载及执行。成交未对账也仅暂停对应币种。删除并重建猎手不能绕过已有亏损记录。北京时间每日06:00重置，模拟API与真实API计数隔离。原有账户级最大回撤、日/周风险保护仍生效。

历史API按50笔分页，支持已成交/含取消筛选，无100笔总限制；已停止猎手仍可通过面板的历史选择器查看。枢轴历史保存当次K线、极值、参数，回看使用冻结的枢轴图。
