# v0.2.149 交易响应与推送同步

客户端接收服务器按账户定向的 OKX 订单、持仓、余额和条件单变化事件，
250ms 合并突发后只刷新相关部分。推送有效时暂停高频持仓查询，并每 30s
校验快照；老服务器/断线时继续原查询。任务与收益进度每 5s 更新，重复
请求合并，成交事件立即触发更新。

下单成功回执即返回，不等待账户、历史单等查询。保留回执状态，成交以
后续交易所数据为准。持仓和当前挂单先到先显示，历史查询可继续后台执行。
账户、交易所和服务器切换丢弃旧请求结果；更新在读取过程中到达会触发
一次后续读取。接口和策略参数保持兼容。

验证覆盖：慢历史请求不阻挡持仓显示；重叠刷新合并；ACK 不等待后台刷新；
账号切走再切回不接受旧响应；持仓事件不查询历史订单；推送突发、超时、
模式/交易所隔离及重连恢复。

全套客户端测试以 2 个 worker 运行：889 通过、1 个 GPU 环境测试跳过。
高并发默认运行的旧挖掘启动用例曾超时，限定 worker 后整套通过；不修改
挖掘实现或测试超时。另增查询错误持续显示及慢旧快照不覆盖新推送回归。
TypeScript 检查与生产构建通过。
