# v0.2.189 因子进化取证与自动审查

从收藏或运行任务进入因子进化后，用户选择的模型可以获得服务器冻结的训练/验证证据，包括真实 K 线、原公式逐层输出、归一化解释及日志复盘。模型可在每轮最多三次按索引查询证据，再提交修正公式树。最终封存数据不会交给模型。

页面新增原配方取证、运行信号复算、自动测试、AI 假设与实测结果、失败原因和解决方案，并支持导出研究报告。缺少记录窗口或逐笔行情时会说明无法精确复现。

只有服务器完成结构/分支语义、因果一致性、扣费、双倍成本、Walk-Forward、相对原式改善及一次最终封存验收，用户才可以点击保存或替换。运行任务在持仓及委托清零后生效。旧版通过结果必须重新研究。

挖掘的公式准入改为逐分支分析，修正 STD/SNR/DIV/NEG 的方向判断漏洞，拦截过深或过长依赖，并提示分位作除数和重复归一化风险。恢复的历史结果及分片结果也必须通过新准入。既有公式的数值执行口径不变。

本次没有强行替换 admin 的雪崩-15分钟、ADA-15分钟、波卡日周期：修正候选未通过收益与稳健性标准，DOT 的长期资金费率覆盖也不足。服务器研究记录见 [公式取证与验收报告](https://github.com/roberts9012062/crypto-trader/blob/codex/multi-cycle-hunter/docs/factor-evolution-evidence-2026-10-13.md)。短线部分成交问题留待前项确认后处理。

验证：桌面类型检查、22 项相关 Vitest、30 项原生内核测试及生产构建通过；浏览器验证了真实 AVAX 取证展示、失败门禁、导出、旧版门禁和 480px 布局。
