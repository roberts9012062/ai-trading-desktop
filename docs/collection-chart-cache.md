# 在线图表三天增量缓存

## 行为

API VALUE COLLECTION 的在线图表按来源、OKX 永续合约、周期独立保存到本机 IndexedDB。沿用统一数据库及 `kline-history` store，使用 `collection-chart-v1` 命名空间，不复用旧业务服务或研究数据。缓存中不保存 Key、票据或账户凭据。

首次打开一个合约的周期时，下载最近三个完整自然时长日加当前桶的数据；为保证长周期图表可用，至少保留 240 根，调用者请求更多时保留请求数量。1m 为 4,321 根，5m 为 865 根，15m 为 289 根。按实际打开的图表填充，不后台批量下载全部 60 个合约和全部周期。

每次进入，包括同进程切换回来和重启：

1. 等本机 Key 读取完成，再发请求；并发启动共用同一次读取。
2. 从本地加载缓存，校验时间戳、周期对齐、北京时间标签、来源、价格和成交量；去重并拒绝未来时间。
3. 每次从接口中心刷新最新两根，覆盖形成中及刚收盘的数据。更早的未确认收盘数据也重新获取。
4. 逐桶检查滚动窗口，按连续缺失区间、每页最多 500 根补充。保留 OKX `after` 的排他游标语义。
5. 分页落盘保存进度；中断可续补。完整校验后才返回给图表；慢下载跨桶时再追赶一次最新尾部。
6. 裁掉窗口外数据、排序保存，随后开放图表。缓存完整时一般只需最新两根的一次行情读取。

应用持续开启时，实时流中确认收盘的 K 线也会写入已存在的同源缓存，并裁剪滚动窗口；重复收盘帧不重复写盘。形成中的价格仍实时更新，下一次进入用最新两根完成最终校验。

日线沿用 OKX 的 UTC+8 日界线。没有更早数据的新上市合约允许短历史，内部缺口不允许伪造平价 K 线。每次重新取数确认可用范围，不信任缓存中保存的范围标记来跳过检查。

网络或权限失败立即显示“核对未完成”和重新核对按钮，保留本机数据及已下载页，不再让 Collection 图表静默等待旧的 90 秒空数据重试窗口。校验未完成的数据不会冒充实时行情。实时 WebSocket 与小规模尾部恢复继续独立运行；显式向左翻页保留原有历史分页行为。

## 验证

`src/lib/collection-chart-cache.test.ts` 使用真实 IndexedDB 事务替身和排他游标数据源，覆盖三天保留、重启、内外缺口、损坏/重复数据、一个小时离线、并发合并、身份变化、日界线、新上市短历史、下载续传、损坏范围标记和慢下载追赶。`collection-config.test.ts` 覆盖原生 Key 并发读取。

真实浏览器验收入口为 `scripts/verify-collection-cache.py`，通过环境变量 `COLLECTION_LIVE_KEY` 提供已授权公共行情 Key，实际挂载图表；业务接口返回测试空值，不连接账户或发出金融写操作。验收项目：冷下载、重启仅补尾、删除中间一根后定点修复、网络中断提示和人工重试、核对后实时动态更新。测试 Key 不写文件，浏览器临时证据保存在本机忽略目录，不进入提交。

第一次三天下载仍取决于用户到接口中心的网络速度；缓存不能消除首次下载和每次最新行情校验的网络等待。磁盘不可用时在线核对仍可完成，但无法持久保存以加速下一次启动。

2026-10-24 发布前检查：类型检查、生产前端构建和 14 个文件的 63 项定向回归通过。最终真实浏览器测试确认 4,321 根分钟线完整、重启只刷新尾部、单根内部缺口定点补充、断网后按钮重试和实时更新均通过，页面异常为零。开发预览测试机器记录首次分钟线窗口下载 47.05 秒；整页重载重新配置测试 Key、日线核对再切分钟线合计 13.98 秒。此耗时包含测试环境开销，不作为安装版速度承诺。证据位于忽略目录 `.local-data/collection-cache/browser-evidence.json`。
