# 短线实验室第一阶段改造

桌面版本：v0.2.102。日期：2026-10-05。增加新任务搜索配置和执行复核，兼容原研究路径与已运行任务；没有自动替换“15周期短线”的因子或参数，没有为验收发送交易订单。

## 使用方式

1. 在短线因子实验室保持“优化短线”开启，下载连续逐笔历史后开始挖掘。CPU、GPU及原生搜索均接收同一个新增特征范围配置。未设置该字段的旧任务保留原搜索范围。
2. 优化模式加入10个简单模板种子、低相关组合搜索和0.25离散信号门，优先搜索桌面与服务器均可计算的特征，排除服务器不可计算的逐笔特征及存在时区差异的日历特征。未降低原研究资格门，也未改写冻结CPU/GPU评分语义。
3. 选择单个候选或前8候选的等权组合。设置保证金、1–50倍杠杆、逐仓/全仓、保证金止盈止损及自动锁利；可以读取绑定OKX账户吃单费率。
4. 点击“复核当前挂载组合”。浏览器Worker按形成中K线生成因果分数，服务器用生产DecisionEngine复核离散开平仓。复核按币种游标读取目录并逐日载入所需归档，避免同时保留全部历史文件。报告显示净盈利、净胜率、平均净盈亏比、净利润因子、净期望、最大回撤，以及双倍费用/滑点和额外一步成交延迟的压力结果。可以导出冻结参数、数据摘要哈希和模拟成交账本。参数/因子变化立即作废旧报告。
5. 挂载时携带相同的新执行配置，创建后的任务尚未启动。是否启动仍由用户在AI交易页操作；沿用账户盘别、VIP/配额等现有规则。

## 新执行规则与修复

- 入场阈值±0.25，连续3步确认；中性退出区收窄到±0.10并连续6步确认，反向信号仍按原确认机制退出。目的在于减少弱信号震荡造成的频繁退出，效果需由扣费报告验证。
- 新模式采用吃单执行；开仓经现有live_trading链路附带本任务数量对应的原生止损。止损百分比基于保证金，按杠杆换算价格距离。止损后需分数退出原方向并重新确认，不在持续相同信号上立即重开。
- 新模式持久化下单意图；回报不确定时暂停等对账，避免自动重复提交。平仓后等待交易所确认完整成交，再清理本任务记录的原生止损单，允许下一轮。不会取消其他任务或手动仓的止损。
- 兜底/锁利/移动止盈采用市价平仓；信号过期和禁止新增仓位的开关不会阻止减仓动作。市价成交及原生止损仍可能发生滑点，无法保证精确成交在阈值。
- 新默认配置为100U、5倍逐仓、止损5%、止盈20%、自动锁利及1次冷却，可自行更改。止盈/止损名义配置比例不是实际平均盈亏比；锁利、信号离场和费用都会改变结果。
- 新`shortline-eval-v2`显式对齐桌面与服务器因果归一化窗口及公式编码，旧v1保持原行为。1分钟预热上限提高至6000根，超过常规缓存深度时分页拉取，历史不足明确报错。

## 复核标准和边界

研究报告检查全段至少100轮、后半段至少50轮，全段及两半段净期望为正，净利润因子至少1.3，实际净盈亏比至少2:1（优化目标3:1），成本压力仍盈利且数据无缺口。当前数据来自Binance逐笔归档，报告明确显示“尚未独立验证OKX”，不会签发实盘通过证书。

本阶段新增的是独立的执行复核按钮，不是将全部遗传候选自动按完整开平仓账本重新排名。要继续完成自动执行目标优化，仍需OKX逐笔历史持续采集、完整资金费、盘口/部分成交建模、独立封存数据及重复搜索偏差检验。前后半段复核不能替代未参与搜索的样本外验收。

当前回放按后续观察价格、逆向滑点和开平仓费用模拟成交；未平仓浮盈不计入胜率。资金费输入按现金流处理，但本地归档没有完整资金费。没有虚构逐笔行情，没有声称提高候选数量就等于提高收益。已运行任务的策略参数保持原样，新参数应先用同一配置复核再决定是否运行。
