# 猎手运行中的盈亏兜底（v0.2.147）

猎手卡片新增“盈亏兜底”，可随时分别启用、关闭、修改最大收益平仓和最大止损。沿用保证金收益率口径及止盈至少10%、止损至少5%的验证，无额外上限。可靠的当前持仓已越过新阈值时，弹窗提示并显示“保存并触发平仓”。

保存只发送两个兜底字段。服务器在同一事务更新该用户、该交易模式的猎手配置与所有未结束子任务，历史单不变，后续新机会继承。保持锁利状态、已提交平仓、冷静期、仓位和其他退出规则。

反弹与枢轴猎手在下一次风险评估同步保护单。显式设置版本允许修改本任务的保护单至更宽止损；关闭兜底止损时撤销自己的兜底保护，枢轴极值保护仍保留。未成交入场携带旧保护参数时先撤单再重新扫描；部分成交先保护实际持仓再撤余单。设置请求本身不调用交易所。

趋势V4及旧趋势子任务使用同样的收益率兜底评估，但保留其结构止损、风险预算与趋势退出。没有显式动态修改过的旧趋势配置继续维持原有行为，避免新版本启动时意外激活原先未使用的兜底默认值。

验证：前端类型检查、单元回归及生产构建；后端真实隔离ORM验证所有权/模式、窄接口校验、历史和未来继承、状态保留，以及模拟OKX验证多空放宽/关闭、枢轴边界、撤旧挂单、下一轮兜底全平和避免重复平仓。线上验收只读，不修改用户实际阈值或人为下单。
