# v0.2.215-go.12 · 安全记住服务器登录密钥

服务器握手页增加显示/隐藏登录密钥、在本机安全保存和忘记已保存密钥。按规范化的服务器地址隔离保存，Windows 桌面端使用当前系统用户的 DPAPI 加密与原生安全存储，不把登录密钥写入浏览器 localStorage、sessionStorage、日志或 URL。

下次登录自动带出当前服务器保存的密钥，仍需点击握手连接。输入新密钥并成功握手后才替换旧值；密钥无效会提示输入新密钥，网络失败或验证失败保留旧配置。读取旧配置的迟到响应不会覆盖手动输入或另一个服务器的密钥。取消保存后，成功登录会清除当前服务器的已保存密钥。

单机登录的 API Collection Key 仍选填，不与服务器登录密钥混存。此功能不自动登录、不新建或启动交易任务。
