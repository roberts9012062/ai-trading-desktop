加密货币行情与账户数据接入 API VALUE COLLECTION，并加入本机 SQL 与独立账户执行器。

- 个人中心的数据配置填写 Collection Key；行情、盘口、逐笔、Tick 和实时价格经接口中心接入，合约入口保持 60 个。
- 工作台与交易所页面支持本机账户读取、历史记录缓存和同步服务器。
- 已取得服务器授权的任务支持按唯一执行权接管，跨端保存运行检查点；断线或回执不明时保留原请求并核对。
- 完善暂停、结束并平仓后的普通委托及已确认归属保护单清理。
- 人工普通撤单与按方向平仓由当前执行端协调，提供“核对人工操作”，区分排队、待核对和完成；任务恢复仍需服务器手动启动。
- 常驻备用按套餐权益配置；没有备用覆盖且全部主端退出时，任务锁停，平仓核验后才可重新授权。

自动接管需要业务服务器和接口中心启用配套执行协议并完成账户授权。实盘及常驻托管沿用管理员授权与套餐开关。安装包使用自动更新签名，升级保留本机用户数据。
