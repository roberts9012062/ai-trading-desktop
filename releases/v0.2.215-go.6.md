# v0.2.215-go.6 · 自动同步实盘配置与数据连接提示

首次服务器握手后，自动同步当前明确选择的本地配置中的 API Collection Key 与 OKX 凭据，包含实盘/模拟盘标记。秘密由原生代码从 DPAPI 读取并直接发送，只返回脱敏回执；不会遍历其他用户配置。切换账户、退出或更换服务器时，旧请求不能覆盖新身份。

服务端使用配套 v0.2.4，默认直读 OKX，并可使用已配置 API Collection Key 作为只读备用。客户端显示实际来源、读取时间与过期状态；连接失败提示购买、配置或同步 Key，凭据错误则提示检查口令和读取权限。失败数据不会冒充实时持仓或空仓。

本机 Go worker 新增独立数据连接诊断。网络和备用来源警告在折叠设置外持续可见；这些字段不替代真实退出回执、执行租约或金融授权。任务仍须在线服务器创建，数据同步不自动创建、启动、恢复或交易。

Go 实盘执行引擎已经实现，服务器默认观察模式需要管理员明确启用 -enable-trading，并满足中心可信公钥、账户与订单核验。此发行开发验收采用隔离夹具，没有发送真实订单。

中心专用只读协议已经部署生产，可在不开启金融执行门时读取账户数据。请保留现有本机配置、服务器数据库与 master.key。
