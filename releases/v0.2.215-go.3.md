# v0.2.215-go.3 · 中心检查点同步预览

- 任务托管页新增“同步检查点”和“读取已存检查点”，显示保存版本、记录数量及同步时间。
- 配套 Go 服务器 v0.1.1：完整读取中心现有状态后加密保存；中心状态变化或同步失败时保留原完整镜像。
- 按服务器能力启用新按钮，旧服务器仍可连接；单机模式不开放服务器镜像操作。
- 检查点版本使用十进制字符串传递，避免大整数被 JavaScript 舍入。仅接收元数据，不回显策略密钥或检查点运行值。
- 保留服务器地址＋登录密钥握手、禁止跨地址重定向、会话切换后丢弃旧响应，以及在线新建任务的限制。

本版本仍为 Go 开发预览。完整交易执行、签名注册、中心检查点写入、执行权交接和逐任务操作尚未完成。任务暂存和快照同步均不会启动实盘交易。

此版本按已确认的公共更新分发要求提供；发布并验证后接入现有“检查更新”清单。服务器请另行升级至 v0.1.1，保留原数据目录与主密钥。
