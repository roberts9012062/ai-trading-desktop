# v0.2.215-go.5 · Go 原生任务与故障接管

客户端现已接入 Go 服务器原生任务入口：在线创建 AI、决策、预测与短线任务，保存模型配置，核对中心注册、检查点及实际执行观察。仍使用服务器地址与签发登录密钥握手；单机模式只能操作已有托管任务，不能新建任务。

新增已有旧任务迁移流程：原任务检查、服务器进程见证、暂停、旧本机执行器实际退出确认，再按原 ID 与签发机构提交迁移。结果未知时保留原请求，仅查询核对。管理员须先在服务器导入匹配原公钥的原始签名身份。

内置与旧执行器分离的纯 Go worker，按固定 SHA-256 与大小校验。备用进程应在服务器正常在线时启动并保持存活；默认只观察。需要接管时由用户明确允许，仍由中心核验连续性、权威检查点、未决订单和租约。启动成功不等于接管成功。

新增单机准备删除、执行器重新准备、显式空仓恢复；解除恢复锁后任务仍停止。更新安装会先等待旧执行器与新 Go worker 的真实退出回执，不覆盖未确认进程。

配套服务器 v0.2.0 与中心协议更新。旧中心能力不足时明确阻止操作，更新不会自动部署中心或启用生产交易。此版本的交易测试均使用隔离夹具，未宣称生产实盘验证。请保留原本机输入、服务器数据库和原 master.key。
