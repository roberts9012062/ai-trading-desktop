# v0.2.215-go.4 · Go 托管账户身份验证

交易所凭证区域新增“验证中心账户”和“读取已存验证”。使用 Go 服务已保存的凭证编号发起验证，不再次传递 Secret；显示账户哈希、验证版本及历史时间，不回显原始 UID 或密钥。

仅服务器模式、OKX 凭证和支持账户验证的 Go v0.1.6+ 服务启用。单机模式没有验证入口；旧服务器或未迁移交易所禁用操作。响应必须仍为同一会话、同一凭证和盘别，版本使用字符串；网络错误不自动重试，额外响应字段不会进入界面状态。

需要中心部署 Authorization 票据兼容网关，并启用已有执行隔离与账户绑定协议。旧中心会在读取私有账户配置之前被拒绝，客户端不会回退到带票据的 URL。若设置交易所 API IP 白名单，应使用实际中心私有网关出口；API Secret 只在 Go 服务本机用于签名。

**仍为开发预览。** 已存身份不等于当前交易权限、任务注册或执行权；完整业务准入、签名发布、行情/风控/持仓恢复和安全交接仍在迁移，暂存任务不会自动运行。IP＋服务器密钥登录、单机只能访问既有中心任务的规则不变。

通过既有签名安装包与升级保留数据流程发布。按用户已确认的公共分发要求，发行与签名验收通过后接入现有“检查更新”；不会在用户电脑自动安装或停止交易进程。
