# v0.2.215-go.2 · Go 任务托管开发预览版

- 登录入口改为服务器 IP / HTTPS 地址与后台签发的登录密钥，独立管理短期 Go 托管会话。
- 新增任务托管页面，支持加密保存交易所凭证、在线暂存任务配置、读取 API VALUE COLLECTION 已有托管账户和任务。
- 单机入口直接验证接口中心 Key 并使用本机原生安全存储，不依赖业务服务器；单机模式不能新建任务。
- Go 托管连接同时禁止浏览器和 Tauri 原生 HTTP 重定向，避免握手 Key、会话和交易所凭证转发到另一地址。
- 新会话与旧 JWT / 本机执行器上下文分离，避免将 Go 登录密钥误当作旧账号的交易权限。

本版本用于验证新连接与界面。Go 后端仍为 v0.1.0 开发基础版：完整 AI / 短线执行、中心签名注册和检查点同步、单机逐任务控制与删除尚未完成。任务暂存不会执行交易，不能用于实盘自动接管。

单机页面目前提供中心已有的“停止账户全部任务”操作，不代表自动平仓、撤单或删除单个任务。已存在的安装资源不代表新的 Go 交易引擎已交付。

该版本为 Go 开发预览版，已接入公共更新清单，所有旧客户端可通过“检查更新”获取。更新后登录方式改为服务器地址与登录密钥；完整交易执行尚未完成，请阅读上述限制。
